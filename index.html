Day to day

Program and project management tools

Tools for the recurring work of running agile teams: planning and scheduling, sprint reviews, and keeping a RAID log current. Each runs in the browser with no server, so nothing proprietary leaves your machine, and AI is used only where it helps, with a person approving the result.

Project Management Central

A project planner with a drag-to-reschedule Gantt chart, task dependencies and milestones, plus a Kanban ticket board. Built with React and TypeScript, covered by automated tests, and deployed by CI.

  • React
  • TypeScript
  • Vite
  • Vitest
  • GitHub Actions

Sprint Summary Generator

Turns a Jira sprint export into a sprint review summary for executives and the team. Metrics are calculated in code; Claude optionally writes the narrative from a redacted payload you can preview, and its answer is checked for invented tickets and figures. Runs in the browser, with no Jira connection.

  • React
  • TypeScript
  • Claude API
  • Vitest
  • GitHub Actions
Live demo Source code

RAID Log Assistant

Keeps a RAID log current from meeting notes and Jira exports. Proposes new risks, assumptions, issues and dependencies, updates and closures, each traced to its source quote, and changes nothing until a person approves it. Works offline with a rules engine, or with Claude for messier notes.

  • React
  • TypeScript
  • Claude API
  • Vitest
  • GitHub Actions
